CHRONOMAP V19 — Prototype autonome
Ouvrir index.html dans un navigateur connecté à Internet.

Fonctions : interface française inspirée de la maquette validée ; modes distincts Carte / Relief / Satellite ; frise 600–2026 avec lecture, pause et pas réglable ; filtre par année des données datées OpenHistoricalMap ; recherche de lieu ; navigation et zoom.

Limites : l’évolution réelle est visible seulement pour les objets dont les dates sont renseignées dans OpenHistoricalMap. La couverture varie selon les lieux et les époques. Le mode satellite utilise l’imagerie actuelle ; les archives aériennes anciennes doivent être ajoutées lorsqu’elles existent. Ce prototype autonome ne remplace pas à lui seul le dépôt ChronoMap existant.
