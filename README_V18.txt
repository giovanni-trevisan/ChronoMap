# ChronoMap V18
Cette archive lance ChronoMap depuis la version actuelle du dépôt et applique le correctif V18 :
- 🗺️ Carte et ⛰️ Relief restent deux fonds indépendants.
- La progression historique vectorielle suit la frise dans Carte et Relief.
- 🛰️ Satellite reste un mode distinct, sans couche historique raster injectée.
- Les fiches, photos, dates et données existantes sont conservées.
- La frise reste le moteur temporel : année -> rendu historique.

Important : cette archive utilise les fichiers actuels du dépôt GitHub au démarrage, donc une connexion Internet est nécessaire.
